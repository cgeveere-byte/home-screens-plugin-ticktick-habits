# TickTick Habits — Home Screens plugin

Shows today's TickTick habits in two groups:

- **Done today** — checked in today
- **Due today** — scheduled for today and not yet done

Weekly "N times" habits (no specific weekday) appear under **This week** until the weekly count is met.

## Install

Copy `manifest.json` and `dist/bundle.js` into a folder under Home Screens plugins, then restart.

Uses the same TickTick API token as the tasks plugin.
